# Политика конфиденциальности приложения «СтройХаб»

Дата последнего обновления: 6 октября 2026 г.

## 1. Общие положения

1.1. Приложение «СтройХаб» (далее — Приложение) разработано для мастеров-отделочников, прорабов и частных застройщиков.

1.2. Мы уважаем вашу конфиденциальность и стремимся защищать ваши данные.

## 2. Какие данные мы собираем

2.1. Мы НЕ собираем персональные данные.

2.2. Все данные, которые вы вводите в Приложении, хранятся ЛОКАЛЬНО на вашем устройстве:
- Названия проектов;
- Описание проектов;
- Расчёты и сметы;
- Настройки приложения (наценка, валюта);
- Данные мастера (имя, телефон, email) — используются только для формирования PDF-сметы.

2.3. Мы НЕ передаём эти данные третьим лицам.

2.4. Мы НЕ используем аналитику, трекеры или рекламные SDK.

## 3. Интернет

3.1. Приложение работает офлайн. Для основных функций интернет не требуется.

3.2. Интернет используется только для:
- Проверки покупок в App Store / Google Play (при оформлении PRO-версии).

## 4. Разрешения

4.1. Приложение НЕ запрашивает доступ к:
- Камере;
- Геолокации;
- Контактам;
- Фотографиям.

4.2. Приложение использует только локальное хранилище устройства для сохранения проектов и расчётов.

## 5. Дети

5.1. Приложение не предназначено для лиц младше 13 лет.

5.2. Мы не собираем данные детей.
